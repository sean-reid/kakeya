# @kakeya/geometry

The mathematical core of the site. Pure TypeScript, no DOM.

Everything the needle does on screen evaluates a motion program built here: slides along its own line and turns about a pivot, nothing else. The test suite holds the one invariant that matters - the needle never leaves the set it sweeps - along with the classical area identities.

## Modules

- `vec`, `polygon`, `union` - primitives, tolerance-based containment, and a grid-sampled area oracle.
- `deltoid` - Kakeya's guessed answer. Tangent chord in closed form: endpoints at parameters -t/2 and pi - t/2, constant length 4r, area 2·pi·r² (pi/8 for the unit needle).
- `motion` - Slide/Turn programs with exact closed-form evaluation.
- `join` - Pál joins: slide out, tilt by sigma = arctan(gap/excursion), slide across, tilt back. Swept area is exactly sigma, split across two unit sectors.
- `perron` - the Besicovitch-Perron tree, following Falconer's presentation: pair adjacent groups, set their hearts adjacent, pull back by (1 - alpha) of the parent base. One step maps area A to (3a² - 4a + 2)A; the depth-1 identity and Chang's closed-form bound are both asserted in tests.
- `sweep` - three sixty-degree fans chained by joins into one continuous half-turn.
- `area-table` - generated by `scripts/area-table.ts`: union areas measured by exact clipping and grid sampling, which must agree. Regenerate with `pnpm exec tsx scripts/area-table.ts`.

## Measured areas

The half-disc sweep is 1.5708; the deltoid is 0.3927. One fan's tree falls from 0.385 at depth 1 to 0.119 at depth 9; the full three-fan set from 0.960 to 0.356. Join budgets scale like 1/excursion (about 0.03 at excursion 100). From depth 9 on, tree plus joins undercuts the deltoid.
